### 🤖 AI / ML projects

| Project | What it does | Built with |
|---|---|---|
| [**Document Q&A Assistant (RAG)**](https://github.com/msulemanengineer/AI-Document-Q-A-Assistant) | Ask questions about a PDF and get answers grounded **only** in that document, with the source passages, page numbers and similarity scores beside every answer. Says *"not found"* instead of guessing. RAG pipeline in plain Python, no LangChain. | sentence-transformers · FAISS · FastAPI · Streamlit · OpenAI / Anthropic |
| [**Resume–Job Matching**](https://github.com/msulemanengineer/AI-Resume-Job-Matching-System) | Compares a resume and a job description by **meaning**, not keywords (MiniLM embeddings + cosine similarity), plus an explainable skill-coverage score. The formula is always shown next to the number. | sentence-transformers · PyMuPDF · FastAPI · Streamlit |
| [**Customer Review Sentiment Analysis**](https://github.com/msulemanengineer/Customer-Review-Sentiment-Analysis) | Classifies reviews as positive or negative and shows **which words decided it**. **82.1% accuracy** on 597 unseen reviews (ROC-AUC 0.895), with the overfitting and limits documented. | scikit-learn · TF-IDF · Logistic Regression · Streamlit |
| [**Movie Recommendation System**](https://github.com/msulemanengineer/movie-recommendation-system) | Content-based recommender: TF-IDF vectors over each movie's metadata, ranked by cosine similarity, served through an API with TMDB posters. | pandas · scikit-learn · FastAPI · Streamlit |

➡️ Interactive versions of these ideas run in the browser in the [**Lab**](https://msulemanengineer.netlify.app/lab).
